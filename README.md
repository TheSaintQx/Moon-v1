# Moon v1 — Лунный Ассистент

Три функции Yandex Cloud, которые вместе дают голосового игрового ассистента
для Алисы: знания по игре, анализ кадров с телефона и оверлей поверх игры.

Версии v1: `moon-knowledge-engine` 0.8.0, `moon-vision` 4.0.0,
`moon-skill` 10.0.

Что даёт v1 по сравнению с предыдущей загрузкой:

- смена игры на стриме больше не смешивает два экрана: старые ответы, маркер
  и незавершённые вопросы отменяются, а статус прогрева новой игры не затирается;
- сбой модели повторяется один раз вместо «не могу подтвердить»;
- `?diag=1` показывает всё состояние и последние ошибки без логов облака;
- раз в час в бакет кладётся копия состояния (`backup/state-*.json`);
- токен уходит заголовком `X-Moon-Token`, в адресах его больше нет;
- зависший фоновый прогрев не дублируется каждые две минуты.

## Структура

| Файл | Что это |
| --- | --- |
| `moon-skill-index.js` + `moon-skill-core.js` | навык Алисы; адаптер переводит вопрос в асинхронный вызов |
| `moon-vision-index.js` + `moon-vision-core.js` | зрение, база знаний, кэш ответов, `answer_ready` для оверлея |
| `moon-knowledge-index.js` | база знаний: вики → индекс в Object Storage → поиск с выдержками |
| `tests/` | локальные тесты с подменой S3, базы знаний и модели |
| `tools/package.sh` | собирает `dist/*.zip` для загрузки в облако |
| `ИНСТРУКЦИЯ.md` | что изменилось и как разворачивать |
| `CHANGELOG.md` | история версий, состав v1 и известные ограничения |

## Как это работает для любой игры

1. Игрок называет игру — навык отправляет её в `moon-vision`.
2. `moon-vision` вызывает `?warm=1`: база знаний по названию находит вики,
   регистрирует игру и загружает обзорные статьи (персонажи, локации,
   предметы, механики, сюжет) в локальный индекс. Если прогрев не успел —
   его сам запускает первый кадр нового стрима (или первый `?poll=1`),
   а если и этого не было — первый вопрос. Всё отдельной invocation,
   параллельно работе, без задержки ответа.
3. Вопрос получает намерение (`characters`, `locations`, `compare`, …),
   база подмешивает к выдаче обзорную статью и выдержки из нескольких статей,
   а модель склеивает из них ответ.
4. Если локальная выдача слабая — включается полный поиск с вики.

Списка поддерживаемых игр нет: вики ищется по названию, база хранится
в `kb/games/<slug>/`.

## Сборка архивов

```bash
./tools/package.sh
```

В архиве точка входа всегда `index.js`, как ждёт Yandex Cloud.

## Проверка

```bash
node tests/kb.test.js
node tests/vision.test.js
node tests/skill.test.js
```

Тесты работают без облака и без секретов: Object Storage заменён памятью,
внешняя сеть заблокирована, база знаний и модель подменены.

Проверить именно то, что лежит в архивах:

```bash
KB_MODULE="$PWD/dist/moon-knowledge-engine/index.js" node tests/kb.test.js
VISION_MODULE="$PWD/dist/moon-vision/moon-vision-core.js" node tests/vision.test.js
SKILL_MODULE="$PWD/dist/moon-skill/moon-skill-core.js" node tests/skill.test.js
```

Покрытие v1: база знаний — 33 проверки, vision — 68, навык — 13.

Быстрая проверка живого стенда — `?diag=1` у moon-vision:
версия, игра, прогрев, последние ответы с временем и источником, ошибки модели.
