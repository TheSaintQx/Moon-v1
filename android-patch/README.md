# Правки приложения: готовый ответ в оверлее

Два файла. Заменяются целиком, других изменений в проекте не нужно.

| Файл | Куда положить |
| --- | --- |
| `FrameCapture.java` | `app/src/main/java/com/limelight/FrameCapture.java` |
| `OverlayView.java` | `app/src/main/java/com/limelight/OverlayView.java` |

## Что теперь происходит

1. Приложение, как и раньше, опрашивает `?poll=1` каждые 1,5 секунды.
2. Если сервер уже собрал ответ, в том же JSON приходит новое поле `ready`.
3. Приложение показывает текст ответа карточкой внизу экрана на 12 секунд.
4. Сразу после показа отправляется `?ack=1&qid=…`, и сервер перестаёт повторять
   это уведомление.

Если сеть подвела и подтверждение не дошло, сервер пришлёт ответ снова —
карточка просто обновится. Ничего не «залипнет».

## Что осталось нетронутым

- Отрисовка маркеров (`rect`, `arrow`, точка) — те же цвета, геометрия, 5 секунд.
- Захват кадров, burst по вопросу, интервал, ротация файлов.
- `?config=1`, `?poll=1`, автоповтор конфига при выключенном захвате.
- Все существующие поля ответа сервера.

Маркер и карточка ответа живут независимо: карточка не гаснет, когда
пропадает маркер, и наоборот.

## Как собрать APK

1. Загрузи оба файла в репозиторий `TheSaintQx/moonlight-assistant`
   по путям из таблицы (через веб-интерфейс GitHub: открыть файл → карандаш →
   вставить содержимое → Commit).
2. Открой **Actions** → **Build Assistant APK** → **Run workflow**.
3. Выбери ветку, в которую залил файлы, и запусти.
4. По окончании скачай артефакт `moonlight-assistant-apk` — внутри
   `app-nonRoot-debug.apk`.

Автоматический запуск в workflow настроен только на ветку `master`.
Если файлы залиты в другую ветку — запускай вручную через **Run workflow**.

## Как проверить, что работает

В Logcat при готовом ответе появятся строки:

```
DIAG: answer shown qid=123456 len=87
DIAG: ack ok qid=123456
```

Если видно `answer shown`, но нет `ack ok` — проблема с сетью или токеном,
повторная доставка будет каждые 1,5 секунды.

## Важно про токен

В `FrameCapture.java` адрес и токен зашиты в коде:

```java
private static final String CLOUD_TOKEN = "…";
```

Это тот же токен, что `AUTH_TOKEN` у moon-vision и `MOON_TOKEN` у moon-skill.
Если будешь перевыпускать токены (раздел 9 инструкции), обязательно обнови
значение здесь и пересобери APK — иначе приложение перестанет получать
и маркеры, и готовые ответы.

## Что не проверено
