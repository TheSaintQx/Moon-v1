# История версий

## v1.1.0 — 9 ноября 2026

Релиз по главному техническому заданию: дефекты не описаны, а исправлены,
недостающие возможности реализованы и покрыты тестами.

### Состав

| Функция | Версия | Что делает |
| --- | --- | --- |
| `moon-knowledge-engine` | 0.9.0 | вики → индекс → поиск по разделам, готовность базы, обновление по `revid`, прямое угадывание вики |
| `moon-vision` | 4.1.0 | два этапа ответа, `?deep=1`, `ack` по стадии, готовность базы по разделам |
| `moon-skill` | 10.1 | короткий ответ сразу, «подробнее» и «ну что там» для разбора, адаптер по заголовку токена |

### Исправленные дефекты

- **Асинхронный путь навыка не работал.** Адаптер перехватывал POST только
  при `?token=` в адресе, а ядро с 10.0 шлёт `X-Moon-Token` заголовком.
  Теперь токен ищется в обоих местах, собственный вызов `?integration=async`
  не перехватывается, ошибка запуска не выдаётся за принятую задачу.
- **Ответ брался из хвоста статьи.** Интервики-ссылки (`[[en:Judy Alvarez]]`)
  становились текстом и выигрывали у раздела «Биография». Теперь они
  вырезаются, служебные разделы отбрасываются, у выдержки есть штраф за
  мусорность и бонус за попадание в раздел по намерению вопроса.
- **`warm: null`** в ответе поиска — теперь всегда объект с `ready`,
  `pages`, `sections`, `ageS`.
- **`reasoning_effort: 'none'` отправлялся всегда** — теперь только если
  задан `MOON_REASONING`.
- **`syncGame` затирал индекс** — запись через слияние (`writeIndexMerged`).
- **Не было обновления базы** — действие `refresh` по `recentchanges`.
- **Замок прогрева не снимался при исключении** — снятие в `finally`,
  частичный результат пишется после каждого шага.
- **`discover` зависел только от веб-поиска** — сначала прямые кандидаты
  `<slug>.fandom.com` и `<slug>.wiki.gg`.
- **`?progress=1` знал только `done`** — теперь `status:'done'` для любого
  готового текста плюс `stage`/`final`/`deep_pending`.

### Новое

- **Два этапа ответа.** `pending → processing_fast → quick_ready →
  processing_deep → deep_ready`. Короткий ответ (до 400 знаков) отдаётся
  сразу, разбор (до 900 знаков, до 6 предложений) доготовляется отдельной
  invocation и не затирает короткий. Если разбор не удался — остаётся
  короткий ответ.
- **`?deep=1`** — отдаёт готовый разбор или продолжает прерванный,
  не запуская поиск заново.
- **`ack` по стадии.** Подтверждение короткого ответа не скрывает разбор:
  он покажется один раз.
- **«Подробнее»** в навыке: «подробнее», «поглубже», «разбор», «детали»,
  «расскажи подробнее». «Ну что там» после короткого ответа тоже забирает
  разбор.
- **Нарезка статей по разделам** и определение группы раздела
  (биография, характер, способности, снаряжение, отношения, геймплей,
  характеристики, квесты, локация).
- **Взвешивание выдержек по idf** и бонус за точное совпадение с названием.
- **`VERSION` в каждом архиве, имена `*-v1.1.0.zip` и `dist/SHA256SUMS.txt`** в сборке.

### Совместимость и порядок загрузки

1. `moon-knowledge-engine` 0.9.0
2. `moon-vision` 4.1.0
3. `moon-skill` 10.1

Навык 10.1 требует vision 4.1 для разбора, но полностью работает и с 4.0:
без `?deep=1` он просто озвучивает короткий ответ. Vision 4.1 понимает
навык 9.8 и 10.0. Обновлять APK не нужно: приложение по-прежнему отправляет
кадры и `?poll=1`, `?token=` принимается наравне с заголовком.

### Проверки

Локальные тесты без облака и без секретов: база знаний 66/66,
vision 83/83, навык 27/27, адаптер 14/14 — и на исходниках, и на содержимом
архивов. В реальном Yandex Cloud релиз не прогонялся: проверены логика,
состояние и сборка, но не фактические задержки вики и ответы модели.

### Известные ограничения

- Реплика Алисы — около 4,5 секунды; разбор в неё не влезает и приходит
  по «подробнее» или через оверлей.
- Разбор запускается отдельной invocation: в облаке это ещё один вызов
  функции на каждый вопрос.
- Первый вопрос по новой теме не мгновенный: нужен вызов модели.
- Название игры должно совпадать с вики («Minecraft», а не «майн крафт»),
  иначе это будет другая база.
- Если в вики нет раздела с ответом, разбор честно вернёт `unk`,
  а короткий ответ останется как есть.

## v1.0.0 — 8 ноября 2026

Первая версия, готовая к постоянной эксплуатации: «Лунный Ассистент» работает
с любой игрой, не требует списка игр и не ломается при переключении игры
во время стрима.

### Состав

| Функция | Версия | Что делает |
| --- | --- | --- |
| `moon-knowledge-engine` | 0.8.0 | вики → индекс в Object Storage → поиск с выдержками, намерения вопросов, сравнение сущностей, фоновый прогрев |
| `moon-vision` | 4.0.0 | приём кадров, база знаний, кэш ответов, `answer_ready` для оверлея, прогрев, диагностика |
| `moon-skill` | 10.0 | навык Алисы: игра, вопрос, «ну что там», прогрев при выборе игры |

### Новое в v1

- **Смена игры на стриме.** При смене игры незавершённые ответы прошлой игры
  отменяются, готовые ответы и маркер прошлой игры не попадают в `ready`
  и `?poll=1`, ответ по прошлой игре не отдаётся по `?answer=1` и `?progress=1`.
  Результат старого прогрева не может затереть статус прогрева новой игры.
- **Повтор при сбое модели.** Один автоматический повтор на 5xx/429/408/обрыв;
  код последней ошибки сохраняется в записи ответа и виден в диагностике.
- **Диагностика `?diag=1`.** Версия, экземпляр, игра, возраст кадра и опроса,
  прогрев, распределение ответов по статусам, размер состояния, последние
  6 ответов с временем и источником, последняя ошибка модели, флаги настроек.
- **Часовая копия состояния** в `backup/state-ГГГГММДДЧЧ.json`.
- **Токен заголовком `X-Moon-Token`.** Навык больше не кладёт токен в адрес;
  vision принимает и заголовок, и старый `?token=`.
- **Защита от зависшего прогрева.** После трёх неудачных фоновых запусков —
  пауза на полчаса вместо вызова каждые две минуты.
- **`?health=1`** теперь показывает и возраст последнего опроса (`poll_age_s`).

### Совместимость и порядок загрузки

1. `moon-knowledge-engine` 0.8.0
2. `moon-vision` 4.0.0
3. `moon-skill` 10.0

Навык 10.0 требует vision 4.0 (токен заголовком). Vision 4.0 понимает и навык
9.8, поэтому порядок «vision → навык» безопасен. Обновлять APK для v1 не нужно:
приложение уже отправляет кадры и `?poll=1`, а `?token=` по-прежнему принимается.

### Проверки

Локальные тесты без облака: база знаний 33/33, vision 68/68, навык 13/13 —
и на исходниках, и на содержимом архивов. В реальном Yandex Cloud релиз
не прогонялся: проверены логика, состояние и сборка, но не фактические
задержки вики и ответы модели.

### Известные ограничения

- Реплика Алисы — около 4,5 секунды; если ответ не готов, его покажет оверлей.
- Первый вопрос по новой теме не мгновенный: нужен вызов модели.
- Название игры должно совпадать с вики («Minecraft», а не «майн крафт»),
  иначе это будет другая база.
