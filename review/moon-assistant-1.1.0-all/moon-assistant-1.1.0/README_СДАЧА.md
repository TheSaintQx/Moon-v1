| База обновлялась только полным перечитыванием | Действие `refresh` по `recentchanges` и `revid` |
| `syncGame` затирал индекс | Запись через слияние |

| Токен APK лежал в репозитории | Берётся из `BuildConfig.MOON_TOKEN` или `TOKEN_FALLBACK` |

## 4. Как проверить после загрузки

1. Скажи Алисе «сменить игру» → «Minecraft», дождись «Принято».
2. Спроси «кто главные герои» — короткий ответ.
3. Скажи «подробнее» — разбор длиннее первого ответа.
4. Открой `?diag=1&token=<AUTH_TOKEN>`: `ver` = `4.1.0`, в `answers` есть
   `quick_ready` и `deep_ready`, в `recent` — поле `stage`.

## 5. Исходники и история

- `Moon-v1/` — рабочий репозиторий, ветка `release/moon-v1-candidate`,
  коммит `2fdad3e` поверх `87d0280`.
- `moon-v1-1.1.0.bundle` — вся история git одним файлом.
- `moon-v1-1.1.0.patch` — изменения относительно базового коммита.

Прямой push в GitHub невозможен: в этой среде нет авторизации. Применить
изменения у себя:

```bash
git clone https://github.com/TheSaintQx/Moon-v1
cd Moon-v1
git bundle verify ../moon-v1-1.1.0.bundle
git pull ../moon-v1-1.1.0.bundle release/moon-v1-candidate
git push origin release/moon-v1-candidate
```

Либо, если история не нужна:

```bash
git apply ../moon-v1-1.1.0.patch
./tools/package.sh        # пересобрать архивы: патч их не содержит
```

Патч намеренно не трогает `dist/`: после его применения в папке останутся
старые архивы базового коммита, поэтому `./tools/package.sh` нужно запустить
(он очищает `dist/` и собирает заново).

## 6. Обязательно: перевыпустить ключи

В репозитории и в переписке фигурировали реальные значения `ACCESS_KEY_ID`,
`SECRET_ACCESS_KEY`, `AUTH_TOKEN`, `MOON_TOKEN`, `KB_TOKEN`, `YC_API_KEY`.
Из истории git они не исчезают, поэтому считай их скомпрометированными:

1. Перевыпусти статический ключ Object Storage.
2. Обнови `ACCESS_KEY_ID` и `SECRET_ACCESS_KEY` в vision и knowledge-engine.
3. Придумай новый общий токен → `AUTH_TOKEN` (vision) = `MOON_TOKEN` (skill).
4. Обнови `KB_TOKEN` в vision и knowledge-engine (одинаково).
5. Перевыпусти `YC_API_KEY` в AI Studio и обнови в vision.
6. Для APK: задай токен через `buildConfigField` или `TOKEN_FALLBACK`
   в `android-patch/FrameCapture.java` и пересобери приложение.

наружу нет.

## 8. Чего кодом не проверить

- Реальные задержки вики и скорость модели в облаке.
- Поведение Алисы и оверлея на живом устройстве.
- Сборку APK: в этой среде нет Android SDK и JDK. Java-файлы изменены точечно
  и используют только те API, что уже были в проекте.
