├── SHA256SUMS-ALL.txt           ← контрольные суммы всех файлов пакета

## Порядок действий

1. Прочитать `README_СДАЧА.md`.
2. Сверить архивы: `cd 01-cloud-archives && sha256sum -c SHA256SUMS.txt`.
3. Загрузить архивы в Yandex Cloud строго по порядку:
   **knowledge-engine → vision → skill**.
4. Прогнать проверку из `README_СДАЧА.md` (раздел «Как проверить»).
5. Перевыпустить ключи — они были в открытом виде (раздел 9 в `ИНСТРУКЦИЯ.md`).

## Как забрать исходники

С историей коммитов:

```bash
git clone moon-v1-1.1.0.bundle moon-v1
cd moon-v1
git checkout release/moon-v1-candidate
```

Без истории, поверх существующего клона на коммите `87d0280`:

```bash
git apply moon-v1-1.1.0.patch
```

Пересобрать архивы после правок:

```bash
cd 03-sources/moon-v1 && ./tools/package.sh
```
